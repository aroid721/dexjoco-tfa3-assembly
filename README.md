# TFA3 Assembly 事件可视化

样例：episode_0001_seed_1000，898帧，50 Hz。采用同步仿真重放视频与触觉，划分为6个候选语义事件。

每个事件至少49帧；短接触变化作为内部标记保留。接触对象和时刻由仿真接触记录辅助核验，属于离线标注证据。

左侧为三视角视频，右侧为固定张开参考姿态下的全表面触觉投影，下方为离线事件描述。手部姿态不代表视频帧中的实际关节姿态。

显示的 Σ|F| 是各外部接触 taxel 的力模之和，不是净合力、特定物体夹持力或插入力。颜色范围为每taxel 0–36 N；箭头缩放为3 mm/N。

本页面提供视频、图片、事件描述及划分元数据。原始触觉、动作文件保留在研究数据目录中。

Caption 是候选离线事后描述；力峰和仿真接触信息不能直接作为部署时已知条件，描述的因果关系与任务完成状态仍需进一步核验。
